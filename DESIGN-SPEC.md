# Ridgeline Roofing design specification

Source of truth: `references/mockup.webp` and the section crops in `references/`, with supplied photography in `assets/`.

## Visual system

- Onyx `#1B1C20`: headings and body copy.
- Canvas `#FCFBFC`: hero, proof, process, FAQ backgrounds.
- Citron `#F3FCD2`: services and testimonial panels.
- Terracotta `#FE6F3E`: primary actions, active service, rating accents.
- Royal blue `#3064E6`: restoration footer.
- Process tints: `#EBF9FD`, `#FDF3E2`, and `#F3F3FD`.
- Display type is geometric, uppercase, tight-tracking; body type is clean and readable.

## Section order

1. Header and hero with roofing image and quote CTA.
2. Built-to-last proof metrics.
3. What we do service list with supporting photography.
4. Three-step process cards.
5. Homeowner testimonial.
6. Questions and answers accordion.
7. Restoration CTA footer.

## Responsive requirements

- Desktop reference: 1440px with a centered 1280px visual container.
- Mobile reference: 390px with 16–20px gutters and stacked cards.
- Interactive controls use visible focus states and touch-friendly sizing.
- Images preserve their supplied photography and use `object-fit: cover` only for the layout crops shown in the reference.
